# 🎓 SANAD STUDIO

A modern educational platform built with Next.js, providing students with AI-powered learning tools and comprehensive course management.

## ✨ Features

- 🌐 Bilingual support (Arabic/English)
- 👤 Student authentication and profiles
- 📚 Course and lecture management
- 🤖 AI-powered learning insights
- 📊 Administrative dashboard
- 📱 Responsive design

## 🚀 Tech Stack

- **Framework**: Next.js 15, React 18, TypeScript
- **Styling**: Tailwind CSS, SCSS, Ant Design
- **State**: Redux Toolkit
- **i18n**: next-intl
- **Auth**: NextAuth.js

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
